# 03. Memory Management (Practice MCQs)

This file contains 40 in-depth MCQs covering Physical vs Logical memory, Internal and External Fragmentation, Paging, Page Tables, Virtual Memory, Swapping, Page Faults, and Memory Allocation algorithms.

**Q1. What is the main purpose of Memory Management in an Operating System?**

B) To manage and allocate the Main Memory (RAM) efficiently among multiple active processes, ensuring they don't interfere with each other

D) To render graphics on the monitor

<details>
<summary>✅ Answer & Explanation</summary>

**Answer: B**
ব্যাখ্যা: মেমোরি ম্যানেজমেন্টের মূল কাজ হলো কোন অ্যাপ র‍্যামের কোন জায়গায় বসবে এবং তারা যেন একে অপরের ডেটা নষ্ট না করে তা খেয়াল রাখা।
</details>

</details>

**Q6. What is "Internal Fragmentation"?**
A) When a hard drive breaks internally
B) When the OS allocates a memory block slightly larger than what the process requested, and the leftover space INSIDE that block is wasted and cannot be used by anyone else
C) When a process crashes
D) When memory is too small

<details>
<summary>✅ Answer & Explanation</summary>

**Answer: B**
ব্যাখ্যা: আপনাকে ৪ জিবির একটি মেমোরি ব্লক দেওয়া হলো, কিন্তু আপনার অ্যাপের সাইজ ৩ জিবি। বাকি ১ জিবি ওই ব্লকের ভেতরেই (Internal) নষ্ট পড়ে থাকবে। এটিই Internal Fragmentation।
</details>

**Q7. What is "External Fragmentation"?**

D) When the OS leaks memory

<details>
<summary>✅ Answer & Explanation</summary>

**Answer: A**

</details>

**Q8. Which memory allocation algorithm searches the entire list of free memory blocks and chooses the block that is CLOSEST in size to the requested process (leaving the smallest leftover hole)?**

B) Best Fit

<details>
<summary>✅ Answer & Explanation</summary>

**Answer: B**
ব্যাখ্যা: Best Fit সবসময় মাপে মাপে জায়গা খোঁজে, যাতে খুব সামান্য জায়গা ফাঁকা (নষ্ট) থাকে।
</details>

</details>

**Q12. What is the fundamental concept of "Paging"?**
A) Reading a book page by page
B) A memory management scheme that eliminates the need for contiguous allocation by dividing physical memory into fixed-sized blocks (Frames) and logical memory into blocks of the same size (Pages)
C) A way to send pager messages
D) Writing logs to a file

<details>
<summary>✅ Answer & Explanation</summary>

**Answer: B**
ব্যাখ্যা: Paging মানে হলো মেমোরিকে আর টানা (Contiguous) থাকতে হবে না। অ্যাপকেও সমান টুকরো (Page) করা হয় এবং র‍্যামকেও সমান টুকরো (Frame) করা হয়।
</details>

---

**Q13. In Paging, what is the relationship between the size of a "Page" (logical) and a "Frame" (physical)?**
A) A Page is always exactly identical in size to a Frame (typically 4KB)
B) A Page is bigger
C) A Frame is bigger
D) They are unrelated

<details>
<summary>✅ Answer & Explanation</summary>

**Answer: A**
ব্যাখ্যা: অ্যাপের একটি টুকরো (Page) র‍্যামের একটি টুকরোতে (Frame) বসবে। তাই দুজনের সাইজ একদম হুবহু সেম হতে হয়।
</details>

**Q14. Does Paging suffer from External Fragmentation?**

C) Yes, but only for large processes
D) It depends on the RAM size

<details>
<summary>✅ Answer & Explanation</summary>

**Answer: B**
ব্যাখ্যা: Paging এর সবচেয়ে বড় ম্যাজিকই হলো এটি External Fragmentation কে জিরো করে দেয়! র‍্যামের যেকোনো ফাঁকা টুকরোতে অ্যাপের টুকরো বসতে পারে।
</details>

<details>
<summary>✅ Answer & Explanation</summary>

**Answer: B**
ব্যাখ্যা: অ্যাপের লাস্ট টুকরোটি (Page) যদি পুরোপুরি ফুল না হয়, তবে ফ্রেমের ভেতরে কিছু জায়গা নষ্ট হয়। তাই Paging এ সামান্য Internal Fragmentation থাকে।
</details>

**Answer: B**
ব্যাখ্যা: যেহেতু অ্যাপের টুকরোগুলো র‍্যামের বিভিন্ন জায়গায় ছড়িয়ে ছিটিয়ে থাকে, তাই OS একটি ম্যাপ বা টেবিল মেইনটেইন করে, যাকে Page Table বলে।
</details>

**Q17. What is the TLB (Translation Lookaside Buffer)?**

**Answer: B**
ব্যাখ্যা: বারবার র‍্যামে গিয়ে Page Table চেক করা সময়সাপেক্ষ। তাই CPU তার নিজের ভেতরের একটি ছোট ক্যাশ মেমোরিতে (TLB) রিসেন্ট অ্যাড্রেসগুলো সেভ করে রাখে।
</details>

**Q30. What is "Belady's Anomaly"?**
